# Review of HPC-Based Multi-Objective Optimization for Ship Weather Routing: reproducibility package

Reproducibility package for the systematic literature search (PRISMA 2020) reported in

> M. Abdalsalam, P. Czarnul, and J. Szłapczyńska, "Review of HPC-Based Multi-Objective Optimization for Ship Weather Routing: Current Experiences, Challenges, and Future Directions," submitted to *IEEE Access*.

## Contents

| Folder | What it holds |
|---|---|
| `protocol/` | Review protocol: research question, review set, eligibility criteria (I1–I4, E1–E5), tiers, data items, evidence classes, appraisal checklist; §10 documents the amendment of 2026-10-05 (search v0.4) |
| `queries/` | Concept blocks (`blocks.json`; the v0.3 blocks are kept in `blocks_v0.3_frozen.json`) and the exact executed queries, filters, dates and counts per database: search v0.4 in `*_queries_v04.json`, the original search v0.3 in `*_queries.json`; citation snowballing in `citation_snowballing_X.json` |
| `hits/` | Per-source result lists (DOI, year, document type, source title; OpenAlex IDs and titles): v0.4 in `*_X.csv`, v0.3 in `*_A.csv` |
| `dedup/` | Deduplicated record lists and deduplication logs: v0.4 (`records_X.csv`, `dedup_log_X.csv`) and v0.3 (`*_A.csv`). Each log row is one retrieved record, and the rows of each deduplicated record are listed together: `rec_id` and `record_title` of the record in `records_*.csv`, the source database, the DOI given by that source (empty when it gave none; such records were matched by title and year), the year given by that source, how it was matched (`first occurrence`, `duplicate (same DOI)`, or `duplicate (same title, year within 1)`), and `order`, the position in the retrieval sequence on which the matching depends |
| `screening/` | Decisions of search v0.4 with one criterion code for each full-text exclusion (title/abstract exclusions by decision only): `decisions_databases_v04.csv` (all database records; title/abstract and full-text stage) and `decisions_other_methods_v04.csv` (citation snowballing and studies known to the authors); author decisions in `author_decisions.md` |
| `extraction/` | Data extraction and reporting-quality scores (QA1–QA6) of the included studies (`extraction_v04.csv`) |
| `scripts/` | Search (01–03, 03b; IEEE Xplore field restriction 03c), deduplication (04; 04c adds the supplementary OpenAlex records), PRISMA counts (07b), citation snowballing (10), figure of evidence classes and parallelism levels (16, Fig. 9) |
| `counts/` | `prisma_counts.json`: every count reported in the manuscript (search v0.4), generated by `scripts/07b_counts_v04.py` |
| `figures/` | Editable sources of Figs. 1–6 (draw.io; LaTeX for the PRISMA flow diagram) and the TOP500 data and script for Fig. 7 (see `figures/README.md`) |
| `evidence_matrix/` | Study-level evidence coverage matrix of the 17 included studies (Table 10): coded data with source locations, coding rules and the script that writes the table |
| `keyword_map/` | Author-keyword maps of the 906 database records (Appendix C): thesaurus, keyword and link tables, sensitivity check and figures |
| `checklists/` | Completed PRISMA 2020 and PRISMA-S checklists |

## Searches

- **Search v0.4 (reported in the manuscript):** Scopus (Elsevier Search API, `TITLE-ABS-KEY`), Web of Science Core Collection (WoS Starter API, `TS=`) and IEEE Xplore (IEEE Xplore Metadata Search API, with the concept blocks evaluated on title, abstract and keywords by `scripts/03c_ieee_field_filter.py`) on 2026-10-05; OpenAlex (supplementary) on 2026-10-06. The executed string is `RX AND MX AND H` (see `queries/blocks.json`); the weather criterion is applied at screening (protocol §10).
- **Original search v0.3:** Scopus, Web of Science and OpenAlex on 2026-09-30 and IEEE Xplore on 2026-10-01, with the string `R AND M AND W AND H`. The amendment and its reason are documented in protocol §10.
- **Other methods:** one round of backward and forward citation snowballing (OpenAlex and Crossref, 2026-10-06) from the reports that had passed full-text assessment at that date, and studies known to the authors from the submitted version of the manuscript whose reports were not among the database records.
- No lower publication-year limit; English; journal articles and conference papers.

Only the SWR × HPC search is analysed in the review. The v0.3 query logs also record a second executed search, in which a multi-objective optimization block (`O`) replaced the HPC block (key `B` in the logs); that literature set is not part of the review.

Re-running the database searches requires the environment variables `ELSEVIER_API_KEY`, `WOS_API_KEY` and `IEEE_API_KEY`, and `CORPORA='{"X": ["RX", "MX", "H"]}'` with `LOG_SUFFIX=_v04` for search v0.4; an optional contact address for OpenAlex is read from `OPENALEX_MAILTO`. Results can differ slightly over time because the databases are updated continuously.

## Requirements

Python 3.10 or later; the only third-party package is matplotlib (`pip install -r requirements.txt`). The search scripts use the providers' web APIs (see above). The keyword maps were built with VOSviewer 1.6.21.

Quick checks from the released files: `python scripts/07b_counts_v04.py` recomputes every PRISMA count (`counts/prisma_counts.json`), `python scripts/16_fig_evidence_parallelism.py extraction/extraction_v04.csv fig9.pdf` redraws Fig. 9, and `python figures/scripts/fig5_top500.py` redraws Fig. 7.

## Data policy

Raw records returned by Scopus, Web of Science and IEEE Xplore are not redistributed, in line with the providers' terms of use; the scripts write these raw database responses to a local folder that is not part of the repository. The package contains the queries, dates, counts, identifiers (DOIs) and minimal bibliographic fields needed to re-trace every step. Abstracts and full texts are not included.

## Figure 7 data

`figures/data/top500_perfdevel_GFlops.csv` contains the TOP500 Performance Development series (sum, #1 and #500, in GFlop/s) retrieved from https://top500.org/statistics/perfdevel/ on 2026-09-30.

## Third-party material

- Bibliographic metadata of the retrieved records in `hits/`, `dedup/` and `screening/` (DOIs, titles, years, venues, document types) and the author keywords in `keyword_map/data/` identify the publications of other authors.
- The item wording of the PRISMA 2020 and PRISMA-S checklists in `checklists/` is reproduced from Page et al., *BMJ* 2021;372:n71, and Rethlefsen et al., *Syst. Rev.* 2021;10:39.
- The TOP500 Performance Development series in `figures/data/` is taken from https://top500.org/statistics/perfdevel/.
- The figure sources of Figs. 1, 3 and 4 embed freely available public icons, which remain the property of their creators.
